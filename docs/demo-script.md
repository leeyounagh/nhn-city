# 시연 영상 대본 — Ashen Kingdom (NAN 2026)

> 목표 3분. **킬러 콘텐츠 = AI 상인 심리 추리 흥정.** 도시 재건은 결과 장치.
> 핵심 메시지: **판정·수치는 코드, 성격·대사·소문은 AI(2레이어).** 매번 다른 반응.
> 데스크톱 중심, 마지막에 모바일 짧게. 각 씬 앞 [ ]=화면, 〔 〕=내레이션.

[ 인트로 컷신 1컷 → 타이틀 ASHEN KINGDOM ]

[ 고향 아이소맵(폐허) 한 컷 ]

## 1. 킬러 — 상인 심리 추리 흥정 (0:20–1:30)  ★ 가장 길게
[ 마을 진입 → 상인 「고물장수 핀치」 흥정창 열기 ]
〔 "상인마다 성격이 다르다. 마법의 책이 성향을 읽어준다 —" 〕
[ 흥정창 좌측 「마법의 책 분석」의 **성향: 실리형** 클로즈업 ]
〔 "이 상인은 '실리형'. 감정보다 계산으로 움직인다." 〕

[ 입력창에 논리적 발언 타이핑 → 제안 ]
  예: "옹이와 갈라짐을 감안하면 값이 과합니다. 품질 대비 합리적으로 조정하시죠."
[ **🎯 정곡을 찔렀다! 호감도 ▲ 값 ↓** 초록 연출 클로즈업 ]
〔 "약점을 정확히 찌르면 — 호감도가 뛰고 값이 내려간다." 〕

[ 대비: 협박 발언 → 제안 ]
  예: "값 안 내리면 가만 안 둔다."
[ **🚫 역효과!** 붉은 연출 ]
〔 "반대로 헛다리를 짚으면 역효과. 상인의 성격을 읽는 게 곧 협상력이다." 〕
[ 수락하고 구매 → 골드/인벤 변화 ]
〔 "가격·판정은 코드가, 성격과 대사는 AI가 맡는다. 같은 상인도 매번 다르게 반응한다." 〕

## 2. AI 변주 — 떠돌이 상인 이벤트 (1:30–1:55)
[ 하루 넘기기 → 「떠돌이 상인」 등장 모달(초상화+말풍선) ]
〔 "가끔은 떠돌이 상인이 문을 두드린다. 희귀템을 권유하는 특별 거래." 〕
[ 흥정한다 → 물물교환 흥정창 1컷 ]

## 3. 재건 — 결과 장치 (1:55–2:25)
[ 고향맵: 팔레트에서 건물 골라 빈 터 탭 → 배치 → 자재 투입 → 완공 ]
〔 "번 골드와 자재로 폐허를 재건한다. 건물이 매일 수입을 낳고, 인구가 늘며 마을이 도시로." 〕
[ 「상인의 신표」 슬롯 클로즈업 → 안내 문구 ]
〔 "최상위 건물은 '상인의 신표'가 필요한데 — 흥정에서 상인의 마음을 완전히 사로잡아야만(호감도 90) 얻는다. 추리와 재건이 하나로 이어진다." 〕

## 4. 페이오프 — 재건된 왕국 (2:25–2:45)
[ (말기 상태) 60채 도시 「전체 보기」 → 「재건된 왕국」 엔딩 모달 ]
〔 "잿더미였던 고향이 다시 왕국이 된다." 〕

## 5. 모바일 (2:45–2:55) — 짧게
[ 모바일 화면: 접이식 팔레트로 맵 최대 + 흥정창(초상화 배경) 1컷 ]
〔 "데스크톱과 모바일 모두 지원." 〕

## 6. 클로징 (2:55–3:00)

## 촬영 메모
- 흥정 씬(1번)에 **가장 많은 시간**. 성향 클로즈업 → 정곡 → 역효과 대비가 핵심.
- 자막 권장(성향/정곡/역효과/신표). 내레이션 없으면 자막만으로도 성립.
- AI 활용 자막 1회: "판정=코드 · 성격/대사/소문=AI (정보 격리·인젝션 방어)".
- 날 넘기기 시 아침 뉴스 모달이 뜨면 빠르게 닫고 진행(편집 컷).
