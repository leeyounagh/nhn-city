## ✅ 잘 되는 것 (강점)
1. **AI 흥정 = 시그니처 기능이 확실히 작동.** 상인이 인게임 말투로 문맥 응답("…10골드 밑으로는 저도 남는 게 없으니…"), 발언을 `자재흠집` 등으로 분류, 값 ↓3, 호감도(41→…)·남은 턴 반영. 데모 임팩트 충분.
2. **핵심 루프 완결**: 이동 → 마을 → 소문/흥정/구매 → 귀가 → 배치 → 투입 → 완공효과. 끊김 없음.
3. **배치 UI 완성도**: 아이소맵, 완공 %, 자재 슬롯(0/5·0/3), PlacementPanel(완공 효과·투입/한번에·이동/회전/삭제·환급 안내).
4. **온보딩 코치**: 단계별 안내·타깃 정확(이동/카드/건물/소문 등).
5. **영속화 정상**: 새로고침 후 골드 355·일차 4·단서(3)·단골 유지.
6. **모바일 레이아웃(최근 작업분) 전부 정상**: 접이식 팔레트로 보드 최대, 2줄 푸터(책 옆 이동/하루/⋯), 월드맵 상단정렬·전체화면, 마을 미리보기·상인 초상화, 흥정창 초상화 배경 페이드.
7. **콘솔 에러 0 / 경고 0** — 데스크톱·모바일 전 구간.
8. **아트**: 인트로 컷신, 마을 미리보기, 건물 스프라이트, 상인 초상화 모두 정상 렌더·분위기 좋음.

## 🔧 발견 / 개선 여지 (우선순위)

### [중] 1. 복귀 플레이어에게 인트로 컷신이 다시 재생됨 — ✅ 수정 완료 (2026-08-08)
> `sessionStorage` → `localStorage`로 seen 플래그 이동. 검증: 첫 방문 인트로 표시(ls=null), 스킵 후 ls="1"·ss=null, 새로고침 시 미재생. 프라이빗 모드 대비 try/catch 폴백.

- 원인: 인트로 "본 적 있음" 플래그가 `sessionStorage`(`lc_intro_seen`, `useGameEngine.ts:178`)라 **탭/브라우저를 닫으면 사라짐**. 같은 탭 새로고침은 OK지만, 다음날 재접속 등 새 세션이면 인트로가 다시 뜬다.
- 문제점: 게임은 진행을 IndexedDB로 영속(재접속 복원)하는데, 인트로 "본 여부"만 세션 스코프라 **영속 정책과 불일치**. 복귀 플레이어가 매 방문 인트로를 다시 봄(건너뛰기는 가능).
- 제안: 인트로 seen 플래그를 IndexedDB/localStorage(영속 플래그)로 이동 → "한 번 본 사람은 자동 스킵". (데모에선 심사위원이 새 탭으로 열 때마다 인트로부터 봐야 하는 점 고려.)

### [하] 2. 새로고침 시 진행 중이던 흥정창이 복원됨 — ✅ 수정 완료 (2026-08-08)
> `persist.ts` normalizeSave(로드)에서 `haggle: null` 강제 → 휘발 세션 상태로 취급, 기존 저장분까지 커버. 검증: 흥정 열고 새로고침 시 흥정창 미복원, 위치·골드·일차는 정상 복원, 콘솔 에러 0.

- 원인: `state.haggle`이 GameState에 포함돼 통째로 영속(`persist.ts` normalizeSave에서 미제거).
- 판단: "흥정 중 이탈 후 이어하기"라면 의도로 볼 수 있음. 다만 리로드 직후 다른 모달과 겹쳐 보이는 경우가 관찰됨(재현 조건 불확실). 정상 닫기(✕) 후엔 `haggle=null`이라 복원 안 됨.
- 제안: 의도가 아니라면 저장 시 `haggle`을 제외(파생/휘발 상태로 취급).

### [하] 3. 뷰포트 리사이즈 시 아이소맵 카메라가 재정렬되지 않음
- 증상: 화면 크기 변경(모바일 세로↔가로 회전 등) 후, 배치한 건물이 화면 밖으로 벗어나 있을 수 있음(카메라 pan이 초기 1회만 (0,0) 중앙정렬).
- 영향: 실사용에선 드묾. 회전 대응이 필요하면 resize 시 마지막 배치/원점으로 재중심.

### [관찰] 4. 온보딩 코치가 지정 버튼 외 클릭을 막음
- 각 단계에서 화면을 딤 처리하고 대상만 클릭 가능. 첫 안내엔 좋지만 자유 탐색이 막힘. `건너뛰기`로 즉시 해제되니 큰 문제는 아님. (원한다면 "둘러보기 허용" 옵션 고려.)

### [관찰/재미] 5. 초반 템포 — 오두막 완공까지 왕복 이동이 김
- 오두막 = 나무 5 + 돌 3인데 나무(삼목골)·돌(무쇠고개)이 서로 다른 마을(각 1~2일). 첫 완공까지 최소 2~3회 이동 → 초반이 다소 느릴 수 있음.
- 참고: 밸런스는 `경제모델.md`에서 이미 다뤄진 영역. 데모용으로 **첫 건물만 단일 자재/근거리**로 두면 초반 훅이 빨라질 수 있음(선택).
