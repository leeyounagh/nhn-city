# 기획서 — Ashen Kingdom (망한 도시의 후계자)

NHN NAN 2026 게임×AI 해커톤 사전과제. 소문 추리 + 상인 거래 + 도시 재건.

## 1. 한 줄 소개
적의 침략으로 무너진 도시의 후계자가, 국보 「마법의 책」의 힘으로 마을을 떠도는 상인들을 소문으로 추적·추리하고, 거래로 물자를 모아 도시의 옛 영광을 되찾는 게임.

- 타깃 — 10~30대. 소문에서 상인을 추리하는 손맛 + 거래 협상 + 도시 성장의 반복성.
- 플랫폼 — 웹 빌드(Next.js + Vercel). 데스크톱 우선.

## 2. 왜 AI인가 (심사 가점 핵심)
- **소문·대화 = LLM 절차생성 추리의 핵심.** 매일 상인의 위치·소지품·원하는 물품이 바뀌고, 그 진실이 정보상·행인·상인의 **자연어 소문**에 부분적·모호하게 흘러나온다. 플레이어는 이 소문을 읽고 "누가·어디서·무엇을 가졌/원하는가"를 추리한다. 고정 텍스트로는 성립 불가 = AI 필연성.
- **거래 협상 = 자연어 설득 게임.** 정해진 선택지가 아니라 말로 상인을 구워삶아 값을 깎거나 희귀템 교환을 성사시킨다.
- **마법의 책 = AI의 서사적 포장.** 책이 소문을 "해독"한다 = LLM이 진실에서 단서를 생성/공개.

## 3. 2레이어 아키텍처 (공정성 보장)
- **코드 소유 (진실·판정)** — 매일의 상인 배치·소지품·원하는물품, 어떤 진실을 어느 소문으로 흘릴지, 거래 성사·가격·교환가치 계산, 경제(기준가·품귀보정·이벤트보정), 건물 요구치, 마법의 책 정보 게이트.
- **LLM 소유 (생성·연기)** — 소문·대화 문장 생성, 상인 페르소나 생성, 거래 대사 연기, 플레이어 발언 분류. LLM은 판정하지 않는다.
- **핵심 원칙** — LLM은 코드가 정한 "흘릴 진실 한 조각"을 자연어로 포장만 한다. 진실·판정은 코드가 소유해 헛추리 유발/불공정을 차단.

## 4. 스토리 (신규 — 망한 도시의 후계자)
적의 침략으로 도시가 무너지던 밤, **퇴직기사**는 나라의 국보 「마법의 책」을 품고 도시의 **후계자**와 함께 탈출한다. 수년의 유랑 끝에 둘은 폐허가 된 고향으로 돌아온다.

마법의 책은 세상에 떠도는 소문과 사람들의 말 속에서 **진실의 조각을 읽어내는** 유물이다. 후계자는 책의 힘으로 상인들을 추적하고, 거래로 물자를 모아 도시를 다시 세운다.

- **왜 상인이 떠도는가** — 침략 이후 고정 상점이 사라졌다. 상인들은 매일 마을을 옮겨 다니며, 오늘 무엇을 지녔고 무엇을 원하는지가 계속 바뀐다. → "매일 바뀜" 정당화.
- **왜 마법의 책인가** — 소문 해독 = 정보 게이트. 도시가 커질수록 책이 더 많은 단서를 읽어낸다.

## 5. 코어 루프
1. **소문 수집** — 현재 마을에서 정보상·행인·상인과 대화 → 마법의 책이 소문에서 단서를 뽑아 **단서 노트**에 기록 (LLM 생성, 코드가 진실 선별).
2. **추리** — 단서를 종합해 "원하는 물품 X를 가진 상인은 누구이며 어느 마을에 있는가, 그가 원하는 물품 Y는 무엇인가"를 추론. (자유형 — 코드가 채점하지 않음. 맞으면 보상, 틀리면 이동시간 낭비.)
3. **이동** — 목표 마을로 이동 (이동일수 소요 → 하루 진행 → 상인 재배치).
4. **거래** — 일반 자재는 **변동 시세로 골드 구매**(멀티턴 흥정으로 값 조정), 희귀템은 상인이 원하는 물품을 내주는 **물물교환**으로만 획득. 호감도·품귀가 조건을 좌우. (LLM 연기, 코드 판정 — 흥정 UI 재사용.)
5. **건설** — 확보한 자재로 건물을 짓고 도시를 키운다. 고호감도 시 특수 아이템 획득.
6. **반복** — 도시 성장으로 책 강화 → 더 많은 단서 해독. 도시를 계속 키워 옛 영광을 되찾는 오픈엔드(별도 승리 판정 없음).

## 6. 시스템 상세

### 6.1 세계 진실 모델 (코드, seed 결정론)
- 매일 D: `merchants[] = { id, 이름, 아키타입, profile, 위치마을, 재고{item:qty}, 원하는물품[], 내일이동여부 }`.
- `towns[]` — 4개 마을. 각 마을은 **대표 업종(業種) 하나**를 지님(특산). 마을 간 이동일수(인접 1~2일).
- **마을 특산 = 업종 단위** (특정 물품이 아니라 산업군).
  - 북서 = **임업** (wood, planks)
  - 북동 = **광업** (stone, steel, bronze, marble, scrap)
  - 남서 = **직물** (cloth, clay, brick)
  - 남동 = **유리세공** (glass, stainedglass)
  - 특산 업종 물품은 그 마을에서 기준가 대비 할인 + 재고 풍부(상인 출현 편향). 타 마을에선 비쌈 → 차익거래 동선 유발.
- `economy` — 기준가 + 품귀보정(최근 구매량) + 이벤트보정(뉴스) + 마을보정(특산 할인).

### 6.2 소문 & 단서 (LLM 생성, 코드 진실)
- 각 정보원이 **진실 한 조각**을 부분적·모호하게 노출: 위치 힌트("북동 마을서 유리 파는 자를 봤다더군"), 원하는물품 힌트("석공이 요즘 강철을 찾는다던데"), 품귀/이벤트 힌트.
- 코드가 어떤 진실을 흘릴지 + (난이도용) 가짜/오래된 단서 여부를 결정. LLM은 말투만 입힌다.
- 단서 노트 = 수집한 소문을 마을·상인·물품 축으로 누적 열람.

### 6.3 거래 (멀티턴, 판정=코드)
- **화폐 모델** — 일반 자재는 **골드로 매매, 가격은 시세(품귀·뉴스)에 따라 변동**. **희귀템은 골드로 못 사고 물물교환 전용**(상인이 원하는 물품을 내줘야 획득). 밸런싱 부담을 줄이려 물물교환 쌍은 희귀템에 한정.
- 상태 — 대상 물품, 현재 제시가/교환요구, 호감도, 남은 협상 턴, 성사/결렬.
- 플레이어 자연어 발언 → LLM 분류(아부/논리/대량/딱한사정/협박/잡담/자재흠집) → 코드가 상인 profile에 대입해 호감도·가격/교환조건 계산.
- 성사 = 골드 구매 또는 물품 교환. 결렬 = 상인이 등을 돌려 오늘 거래 불가.

### 6.4 경제 동역학 (코드, 공정성)
- **물품 속성** — 각 자재는 `기본가격`과 `희귀도(tier)`를 지님. 폭락 이벤트가 나도 **하한가(floor)** 아래로는 안 떨어져 최소 가치 보장.
- **가격식** — `시세 = 기본가 × 품귀배수 × 이벤트배수 × 마을배수` (하한가로 클램프).
  - **품귀배수** — 특정 물품을 최근 많이 구매하면 상승 → 분산 구매 유도. 시간 경과(이동)로 완화.
  - **이벤트배수** — 아래 아침 뉴스가 지정한 물품/업종에 코드 고정 %보정.
  - **마을배수** — 특산 업종 물품은 그 마을에서 <1 (할인), 타 마을은 ≥1.
- **아침 뉴스 방송 (동물의숲 여울 톤)** — 하루 1회 아침에 팝업. LLM이 헤드라인 문장을 연기 생성, 코드가 실제 가격 %보정을 소유(판정). 예: "북동 광산에 노다지가 터졌다!" → 광업 업종 물품 일시 폭락(매입 타이밍). "남서에 한파로 목화 흉작" → 직물 물품 급등.
- **대풍작 / 증산 이벤트** — 특정 마을 특산 업종에 대풍작(임업=풍년, 광업=노다지, 직물=목화풍작, 유리=가마 호황)이 뜨면 그 업종 물품 가격이 일시 폭락 → 싸게 사서 타 마을에 되파는 차익 기회.
- 진행 밸런싱 — 자재 총수요 대비 상인 출현·시세를 코드가 조율해 막힘 없이 계속 성장 가능하게 유지.

### 6.7 생산 시스템 (코드, 도시 성장 보상)
- 도시가 커지면 일부 건물이 **매일 물품을 생산**한다. 도시가 발전할수록 상위/고급 생산품이 해금된다(하위 자재 → 상위 가공재).
- **용도 (b안 — 자급 + 잉여 판매)** — 생산품은 (1) 다음 건설에 자급자족으로 소비하고, (2) 남는 잉여분은 시장 시세로 되팔아 골드화한다. → 생산이 경제 루프에 편입되어 순수 소비원이 아닌 수입원이 된다.
- 생산품도 §6.4의 시세·품귀·뉴스 영향을 받는다(과잉 생산 시 자체 가격 하락).
- 2레이어 원칙 유지 — 생산량·해금 조건·판매가는 코드 소유. LLM은 관여하지 않음.

### 6.5 마법의 책 (정보=힘, 진행 게이트)
- 레벨별 소문 해독량 증가.
  - Lv1 — 단서가 흐릿(위치 대략만).
  - Lv2 — 상인 성향 힌트 + 원하는물품 힌트 선명.
  - Lv3 — 정확한 약점 + 가격 하한 근사 + 가짜 단서 판별 보조.
- 레벨업 — 도시 건설 경험치 + 이벤트 보상.

### 6.6 이동 & 시간 (코드)
- 마을 간 이동 시 이동일수만큼 날짜 진행 → 상인 재배치·소문 갱신·품귀 완화. 시간 압박이 추리·동선 최적화의 긴장감을 만든다.

## 7. AI 활용 요약 (기술문서용)
- 2레이어 분리 — 판정·진실=코드, 소문·연기 생성=LLM.
- 소문 기반 절차적 추리 — 매일 바뀌는 진실을 자연어 단서로 흘림 = AI 필연성 핵심.
- 거래 자연어 협상 — 자유 발언 분류 + 상인 연기.
- 정보 격리 — 상인·정보원은 자기가 아는 조각만 안다. 정답·하한가 미주입.
- 프롬프트 인젝션 방어 — 소문/상인이 진실 전체·수치를 유출하지 않게 시스템 프롬프트로 방어.

## 8. 기술 스택
- Next.js App Router + React + Tailwind + TypeScript, pnpm. Anthropic Claude API(서버 라우트에서만). Vercel 배포.
- 상인 초상화 — Midjourney 사전생성 풀(`--sref` 스타일 통일) + 성향 랜덤 배정(A안), fal.ai 라이브 생성은 선택 데모(B안).
- 건물/마을 — Kenney.nl 무료 에셋.

## 9. 결정 사항 (2026-07-19 확정)
- **화폐 = 골드 메인 + 변동 시세**(품귀·뉴스). **물물교환은 희귀템 전용.**
- **추리 = 자유형**(코드 채점 없음, 단서만 부분 제공).
- **거래 협상 = 기존 멀티턴 흥정 UI 재사용.**
- **맵 = 4개 마을 월드맵(노드 선택) + 마을 진입 시 대화 화면**(걸어다니는 맵 폐기).
- **규모(MVP) = 마을 4, 상인 6, 하루 1회 상인 이동.**

## 10. 단계 계획 (마감 2026-08-10, 1인)
- **P1 진실+소문 (AI 별점)** — 다중 상인 일일 배치 + 소문 생성/단서 노트. 검증: 소문이 진실과 일관, 크레딧 없이 폴백.
- **P2 이동+거래** — 월드맵 이동(일자 진행·상인 재배치) + 거래 협상(흥정 UI 재사용, 골드 매매 + 희귀템 물물교환).
- **P3 경제/뉴스** — 품귀 시세 급등 + 마을 특산 업종 할인 + 아침 뉴스 방송(대풍작 폭락 포함).
- **P4 도시건설 연결 + 생산 + 특수아이템** — 거래로 모은 자재로 건설, 건물 생산(자급+잉여 판매), 고호감도 특수템.
- **P5 배포+산출물.**
- 원칙 — **P1이 별점**. 시간 부족 시 P3~P4 일부 폐기. 손맛·AI는 소문 추리에 집중.
