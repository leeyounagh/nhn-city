# 기획서 — 「마지막 도시」 (가제)

NHN NAN 2026 게임×AI 해커톤 사전과제. 도시건설 타이쿤 + 떠돌이 상인 자연어 흥정.

## 1. 한 줄 소개
붕괴한 세계에서 떠돌이 상인들과 자연어로 흥정해 자재를 모으고, 마지막 도시를 재건하는 타이쿤.

- 가제 후보 — 「마지막 도시」 / 「코덱스: 폐허의 건축가」 / 「유랑상인 흥정록」. 우선 「마지막 도시」로 진행.
- 타깃 — 10~30대 남성. 절차생성 상인 + 흥정 손맛 + 로그라이크식 반복성이 소구점.
- 플랫폼 — 웹 빌드(Next.js + Vercel). 데스크톱 우선(타이쿤 타일 배치 특성).

## 2. 왜 AI인가 (심사 가점 핵심)
- **떠돌이 상인 = LLM 절차생성.** 매번 성격·외모·말투·배경이 다른 상인을 무한 생성 → 리플레이성. 고정 상인 풀이면 AI가 필요 없다. 이 대체 불가능성이 "왜 AI를 썼는가"의 답이다.
- **흥정 = 자연어 설득 게임.** 정해진 선택지가 아니라 플레이어가 자유롭게 말로 구워삶는다. LLM 없이는 성립 불가.
- **마법의 책 = AI의 서사적 포장.** 책이 상인을 "읽어낸다" = LLM이 상인 프로필·약점을 생성/공개. AI를 다이제틱하게 감쌌다는 서술이 기술문서에 그대로 들어간다.

## 3. 2레이어 아키텍처 (공정성·클리어 보장)
지난 프로토타입에서 검증된 구조를 재활용한다.

- **코드 소유 (진실·판정)** — 경제(기준가·하한가·재고), 자재 총수요, 건물·랜드마크 요구치, 승리조건, 경험치, 상인 숨은 성향, 흥정 호감도·가격 계산. → 게임이 반드시 클리어 가능하고 공정하도록 코드가 보장.
- **LLM 소유 (생성·연기)** — 상인 페르소나 생성, 흥정 대화 연기, 플레이어 발언 카테고리 분류. LLM은 판정하지 않는다.

핵심 원칙 — LLM은 플레이어 발언을 카테고리로 **분류만** 하고, 실제 호감도·가격 변동은 코드가 상인 성향에 대입해 계산한다. 헛거래·가격 붕괴를 원천 차단.

## 4. 스토리 (A안 — 문명 붕괴 후 유랑 교역 세계)
옛 문명이 "대붕괴"로 무너진 지 수십 년. 정착지도 상점도 사라지고, 오직 떠돌이 상인만이 폐허 사이를 오간다.

주인공은 죽어가는 스승에게서 두 가지를 물려받는다 — **마법의 책**, 그리고 유언 "마지막 도시를 다시 세워라." 마법의 책은 붕괴 이전의 유물로, 다가오는 상인의 정체·성격·약점을 읽어낸다. 처음엔 흐릿하게만 보이지만, 도시가 커질수록 책의 힘도 깨어난다.

- **왜 상인이 떠도는가** — 붕괴 후 세계엔 고정 상점이 없다. 매번 다른 유랑자가 우연히 도시를 스쳐간다. 같은 자재라도 파는 사람은 늘 다르다. → "매번 바뀜" 정당화.
- **왜 마법의 책인가** — 붕괴 이전 유물. 도시 재건으로 힘을 되찾는다. → 정보 게이트 정당화.

## 5. 코어 루프
1. 코드가 도시 다음 단계에 필요한 자재를 제시한다.
2. 떠돌이 상인이 등장한다 (코드가 재고·기준가 배정, LLM이 페르소나 생성).
3. 마법의 책으로 상인 정보를 열람한다 (책 레벨이 낮으면 조금만 보인다).
4. 자연어로 멀티턴 흥정한다 (LLM 연기, 코드가 가격·성사 판정).
5. 자재를 구매해 건물을 짓는다 → 경험치를 얻는다.
6. 경험치·우연한 이벤트로 마법의 책을 강화한다 → 상인 약점을 더 많이 본다 → 흥정이 유리해진다.
7. 반복. 도시가 성장하고, 랜드마크를 완성하면 승리.

## 6. 시스템 상세

### 6.1 자재 & 건설 (코드)
- 자재 — **13종 3티어** (수치·상인 매핑은 `경제모델.md` 참조).
  - 티어1 기초 — 목재·석재·점토·고철
  - 티어2 가공 — 판자·벽돌·유리·강철·천밧줄
  - 티어3 희귀 — 대리석·청동·스테인드글라스·옛문명의부품
  - 생산체인 없음(전부 상인 구매). 티어 = 어느 건물이 쓰고 어느 상인이 파는가 + 희귀도·가격으로 구현. 건물당 요구는 2~4종으로 제한해 관리 부담 축소.
- 건물 — 각 건물은 자재 요구치 + 완성 시 골드 수입·경험치 부여. MVP 6종 + 랜드마크.
- 랜드마크 — 승리 조건. 여러 선행 건물 완성을 요구해 자연스러운 진행 게이트를 만든다.
- 배치 — 아이소 그리드. **스코프 관리를 위해 슬롯 기반**으로 단순화(자유 배치 최소화). 손맛은 흥정에 몰고 건설은 가볍게.

### 6.2 떠돌이 상인 (코드 + LLM)
- 코드 소유 — 취급 자재+재고, 기준가·하한가, 숨은 성향(persuasionProfile), 초기 호감도.
- LLM 소유 — 이름·외모묘사·말투·배경 페르소나, 흥정 대사, 발언 분류.
- 등장 시 코드가 스펙을 롤 → LLM이 그 위에 페르소나를 얹는다.
- 정보 격리 — 상인 프롬프트엔 자기 스펙만 주입. 다른 상인·경제 전체·정답 미주입.

### 6.3 흥정 (멀티턴, 판정=코드)
- 상태 — 현재 제시가, 호감도(disposition), 남은 흥정 턴(예: 5), 성사/결렬.
- 플레이어 자연어 발언 → LLM이 카테고리 분류(아부/논리/대량구매/딱한사정/협박/잡담/자재칭찬 등) → 코드가 상인 성향에 대입해 호감도·가격 변동 계산.
- 예시 — 자존심형은 아부에 호감도↑ 가격↓, 협박엔 호감도↓↓ 결렬 위험. 탐욕형은 대량구매·즉시현금에 반응.
- 성사 — 최종가로 구매. 결렬 — 상인이 떠나 해당 자재를 못 산다.
- 공정성 — 코드가 하한가 보장(무한 후려치기 불가) + 상한 턴(질질 끌기 방지). 자재 총수요 대비 상인 출현 빈도·가격을 코드가 밸런싱해 클리어 가능성 확보.

### 6.4 마법의 책 (정보=힘, 진행 게이트)
- 레벨별 상인 정보 노출량 증가.
  - Lv1 — 취급 자재만 보인다.
  - Lv2 — 성향 힌트("자존심이 강해 보인다").
  - Lv3 — 정확한 약점 카테고리 + 하한가 근사치.
  - Lv4 — 재고·기분 등 세부.
- 레벨업 — 도시 건설 경험치 + 우연 이벤트(상인이 책 조각을 팔거나 특정 건물 완성 보상).
- 게임적 의미 — 책이 강할수록 상인 약점을 알고 공략해 싸게 산다. "정보가 곧 힘" 루프가 책 강화에 실질 의미를 준다.

### 6.5 경제 밸런스 (코드, 공정성)
- 시작 자금, 랜드마크까지의 자재 총수요, 상인 출현 빈도·가격 분포를 코드가 관리.
- 클리어 검증 — 평균 흥정 성공률로 승리 가능한지 시뮬레이션(반드시 클리어 가능해야 함).

## 7. AI 활용 요약 (기술문서용)
- 2레이어 분리 — 판정=코드, 생성·연기=LLM.
- 절차적 상인 생성 — 무한 리플레이 = AI 필연성.
- 마법의 책 — AI의 다이제틱 래핑.
- 정보 격리 — 상인은 자기 스펙만 안다.
- 프롬프트 인젝션 방어 — 상인이 하한가·정답을 유출하지 않게 시스템 프롬프트로 방어.
- 상인 초상화 — Midjourney 사전생성 풀(스타일 통일) + (선택) fal.ai 라이브 생성 데모.

## 8. 기술 스택
- Next.js App Router + React + Tailwind + TypeScript, pnpm. Anthropic Claude API(서버 라우트에서만 호출). Vercel 배포.
- 상인 초상화 — **Midjourney**로 사전 생성. `--sref`로 스타일 통일, 아키타입별 배치 생성 → `public/merchants/` 저장 + 태그 json 매핑.
- 건물 — Kenney.nl 무료 아이소메트릭 시티 에셋(AI 타일 생성은 일관성 문제로 비채택).

## 9. 아트 파이프라인 (Midjourney)
1. 스타일 레퍼런스 확정 — 톤(다크 판타지/유랑) + 구도(가슴 위 반신, 중립 배경) 고정.
2. 아키타입별 배치 생성 — 자존심/탐욕/외로운/쾌활/음침 × 성별·연령 변주.
3. `--sref`(스타일 레퍼런스)로 50장+ 통일감 유지 생성.
4. `public/merchants/`에 저장 + `{ file, archetype, tags }` json으로 매핑.
5. 런타임 — 코드가 상인 성향 롤 → 해당 아키타입 태그 초상화 배정 → LLM 페르소나가 그 위에 얹힘.

## 10. 스코프 / 마감 리스크 (2026-08-10)
- 최대 리스크 — 타이쿤 타일 배치(아이소 그리드·깊이정렬·배치 로직). 슬롯 기반 단순화로 축소.
- MVP 범위 — 자재 4종, 건물 5~6개, 랜드마크 1개, 상인 성향 4종, 책 레벨 3단계, 멀티턴 흥정.
- 원칙 — 손맛과 AI는 흥정에 집중, 도시건설은 목표/틀로 경량 유지. (지난 프로토타입 "노잼" = 얄팍한 루프 → 이번엔 흥정 깊이로 해결.)
