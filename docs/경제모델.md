# 경제·데이터 모델 (1차안) — 「마지막 도시」

코드가 소유하는 "진실" 데이터의 설계도. 이 문서가 서버 전용 데이터 파일(추후 `src/lib/server/economy.ts` 등)의 원본이 된다. 수치는 1차안이며 클리어 밸런스 시뮬 후 조정한다.

통화 = **골드**. 가격은 자재 1개당 단가.

## 2. 상인 시스템

상인은 등장할 때마다 코드가 **전문화**와 **성향**을 각각 롤한다. 그 위에 LLM이 페르소나(이름·외모·말투·배경)를 얹는다.

### 2.1 전문화 (취급 자재 결정)
| 전문화 | 취급 자재 | 톤(LLM용 힌트) |
|--------|-----------|----------------|
| 목재상 | wood, planks | 투박·성실 |
| 석공상 | stone, brick, marble | 자부심 강한 장인 |
| 고물상 | scrap, steel, relic | 수상·능글, relic은 책 Lv3+에만 노출 |
| 유리세공상 | glass, bronze, stainedglass | 예민·까다로움 |
| 직물잡화상 | clay, cloth | 수다·친화 |
| 만물상 | 티어1 전부 소량 | 두루뭉술, 가격 +15% 마크업 |

### 2.2 성향 (persuasionProfile — 흥정 약점, 전문화와 독립적으로 롤)
| 성향 | 약점 카테고리(호감도↑) | 역효과 카테고리(호감도↓↓) |
|------|------------------------|---------------------------|
| proud 자존심형 | flattery(아부) | threat(협박) |
| greedy 탐욕형 | bulk(대량구매) | sob(딱한사정) |
| lonely 외로운형 | smalltalk(잡담), sob | threat |
| pragmatic 실리형 | logic(논리), quality(자재흠집) | flattery |

### 2.3 등장 로직
- 하루(day)마다 상인 1~2명 등장. 전문화·성향은 가중 랜덤.
- 재고 = 취급 자재별 랜덤 수량(예: 티어1 5~12, 티어2 3~8, 티어3 1~3).
- 초기 제시가 = 기준가 × (1 + variance), variance 0~0.2.

## 3. 흥정 수식 (멀티턴, 판정=코드)

상태 = { 제시가 offer0, 호감도 disposition(0~100), 남은 턴 turns(=5), 성사/결렬 }.

1. 매 턴 플레이어 자연어 발언 → **LLM이 카테고리 1개로 분류** (flattery/logic/bulk/sob/threat/smalltalk/quality).
2. 코드가 `호감도 += Δ(카테고리, 성향)` 적용 (0~100 클램프).
3. 현재가 = `floor + (offer0 - floor) × (1 - disposition/100)`.
   - 호감도 0 → 제시가, 호감도 100 → 하한가.
4. quality(자재흠집)는 성사 시 offer0에 일회성 -8% 추가(가격 앵커 인하), 단 성향별 호감도 영향은 표대로.
5. 성사 = 플레이어가 현재가 수락 + 골드 충분. 결렬 = 턴 소진 or 호감도 0(상인 이탈).

### 호감도 Δ 표 (1차안)
| 카테고리 | proud | greedy | lonely | pragmatic |
|----------|-------|--------|--------|-----------|
| flattery 아부 | +18 | 0 | +8 | -3 |
| logic 논리 | 0 | +3 | -2 | +18 |
| bulk 대량구매 | +5 | +18 | +3 | +10 |
| sob 딱한사정 | +3 | -5 | +15 | 0 |
| threat 협박 | -25 | -10 | -18 | -8 |
| smalltalk 잡담 | +5 | -3 | +18 | -2 |
| quality 자재흠집 | -5 | -3 | -3 | +12 |

→ 약점을 모르면 헛발질. 마법의 책이 약점을 알려줘 "정보=힘"이 성립.

## 4. 마법의 책 (3레벨)

| 레벨 | 노출 정보 |
|------|-----------|
| Lv1 | 취급 자재만 |
| Lv2 | 성향 힌트(예: "자존심이 강해 보인다") + 대략 가격대 |
| Lv3 | 정확한 약점 카테고리 + 하한가 근사치 + 고물상의 relic 식별/구매 가능 |

- 레벨업 = 건물 완성 누적 경험치 임계치. 초반 건물 전부 완성 → Lv2, 중반 건물 전부 완성 → Lv3.
- 우연 이벤트(상인이 책 조각 판매 등)는 확장 항목.

## 5. 건물 · 랜드마크

완성 시 골드 수입(/day)과 경험치 부여. 상위 티어는 하위 건물 완성을 선행 요구(진행 게이트).

| 건물 | 요구 자재 | 수입/day | 경험치 | 선행 |
|------|-----------|----------|--------|------|
| 오두막(주거) | wood5, stone3 | +8 | 10 | - |
| 창고 | wood4, clay4, scrap2 | +5 | 10 | - |
| 우물 | stone6, scrap3 | +3 | 10 | - |
| 작업장 | planks6, brick5, steel3 | +12 | 20 | 초반 3종 |
| 시장 | planks5, cloth4, glass3 | +18 | 20 | 초반 3종 |
| 성벽 | stone10, brick8, steel5 | +5 | 20 | 초반 3종 |

## 6. 경제 흐름 & 클리어

- **루프** = 완성 건물이 골드 수입 → 골드로 자재 흥정 구매 → 건물 건설 → 수입 증가·경험치→책 강화 → 반복 → 랜드마크 완성 = 승리. 흥정을 잘할수록(약점 공략) 싸게 사서 빠르게 성장.
- 시작 자금 = 400골드 (1차안).
- 일(day) 종료 시 완성 건물 수입 합산 지급.
- **클리어 검증(필수)** = 하한가 근처로 사는 이상적 플레이 기준 총비용 ≈ 랜드마크 포함 2,300골드대. 평균 흥정 성공률·수입 증가 곡선으로 N일 내 승리 가능한지 시뮬 후 시작자금·수입·가격 조정. (지난 프로토타입 원칙 = "반드시 클리어 가능".)

## 7. 2레이어 격리 (무엇이 어디에)

- **서버 전용 진실** = 자재 가격표, 상인 전문화·성향·재고, 호감도 Δ표, 흥정 수식, 건물 요구·수입, 책 레벨 규칙, 시작자금. 클라이언트에 미노출.
- **클라이언트 공개** = 현재 노출된(책 레벨에 따른) 상인 정보, 내 자재·골드, 건물 상태, 현재 제시가·호감도·남은 턴.
- **LLM 역할** = 상인 페르소나 생성 + 흥정 대사 연기 + 발언 카테고리 분류. **판정·수치 계산은 절대 LLM이 하지 않음.**
- **인젝션 방어** = 상인 프롬프트엔 자기 스펙만. 하한가·약점·정답을 대사로 유출하지 않도록 시스템 프롬프트로 방어.

## 8. 열린 수치 (밸런스 패스에서 확정)
- 시작 자금, 건물 수입/day, relic 가격, 흥정 턴 수(현재 5), 상인 등장 빈도.
- 호감도 Δ 표 미세조정 (역효과 강도).
