ASHEN KINGDOM

망한 도시의 후계자

NHN NAN 2026 게임 × AI 해커톤 · 사전과제 · 1인 개발
상인의 마음을 읽어야, 마을을 되살릴 수 있습니다.

폐허가 된 고향으로 돌아온 후계자가 되어, 마을에 떠도는 소문으로 상인을 추리하고 AI 상인과 대화·흥정해 자재를 모아 도시를 재건하는 게임입니다.

게임 개요

매일 위치가 바뀌는 상인을 소문으로 찾아, 그의 성향을 읽고 그에 맞는 말로 설득해 값을 깎습니다. 거래로 모은 자재로 폐허를 건물로 채워 마을을 다시 일으킵니다. 상인의 성격·대사·소문은 AI(Gemini)가 매번 다르게 생성하고, 가격·성공/실패 같은 판정은 코드가 맡아 공정성을 지킵니다.

게임 방법 — 목표 · 조작 · 종료

목표잿더미가 된 고향을 재건한다. 거래로 자재를 모아 건물을 짓고 인구를 늘려, 마을을 다시 왕국으로 되살린다.
핵심 재미소문으로 상인의 위치를 추리하고, 대화로 성향을 파악해, 성향의 약점을 찌르는 흥정으로 값을 깎는 것.
조작데스크톱은 마우스, 모바일은 터치. 「이동」으로 월드맵에서 마을 선택 → 상인의 「흥정」 클릭 → 입력창에 자연어로 설득 후 「제안」 → 건물 팔레트에서 골라 빈 터를 탭해 배치 → 자재 「투입」으로 완공. 아이소맵은 드래그 팬 · 핀치/휠 줌.
종료 조건별도의 패배 없이 도시를 키우는 오픈엔드. 재건이 무르익으면 「재건된 왕국」 엔딩 연출에 도달한다.
한 판의 흐름
소문 확인 → 상인 위치 추리 → 월드맵 이동 → 성향 파악 → 흥정(🎯정곡/🚫역효과) → 자재 획득 → 건설 → 인구·수입 성장 → 반복

실행 방법

  • 플레이(권장) — 웹 브라우저에서 아래 배포 링크 접속. 설치 불필요, 링크 클릭만으로 바로 플레이.
  • 로컬 실행 — Node.js 20+ / pnpm 필요. pnpm install → pnpm dev → http://localhost:3000. AI 대사는 GEMINI_API_KEY 설정 시 라이브 생성, 없으면 정적 폴백으로 동작(플레이 가능).
  • 데스크톱·모바일(반응형) 모두 지원.
